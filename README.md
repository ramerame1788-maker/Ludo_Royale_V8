# Ludo V4
نسخة بداية للودو أونلاين: غرف، كود دعوة، أسماء، ألوان، جاهزية، ودردشة.

## التشغيل
1. ثبّت Node.js.
2. داخل مجلد المشروع شغّل:
   npm install
   npm start
3. افتح http://localhost:3000
4. افتح الصفحة في متصفحين لاختبار الغرفة من لاعبين مختلفين.

هذه نسخة تأسيسية؛ منطق المباراة الكامل والعملات والحسابات وقاعدة البيانات يمكن إضافتها في المرحلة التالية.
